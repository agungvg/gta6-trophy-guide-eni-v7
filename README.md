Vice Atlas is an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: every trophy with its official name, description and grade, a step-by-step guide with a source cited on every step, a cited roadmap to the platinum, missable flags built from the official descriptions, and a checklist that saves in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. The guide is plain static files under `app/` and works with the network off.

Built for the make.fun competition [gta6-trophy-guide-01](https://make.fun/?ref=p9r33tb4).
